# Histórico do projeto — Speaker Keep Awake

## Finalidade

Utilitário Windows para impedir que uma saída de áudio Bluetooth entre em repouso durante pausas curtas.

## Origem

Criado numa conversa do Codex em 30 de setembro de 2026. O projeto usa .NET para Windows e mantém código, testes e documentação neste repositório.

## Retomada

Leia o README para compilar o executável e instalar a versão atual. Configurações pessoais, saídas de compilação e transcrições da conversa não fazem parte do repositório.
